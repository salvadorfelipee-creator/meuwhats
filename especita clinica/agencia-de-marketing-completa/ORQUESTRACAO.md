# Como orquestrar as 8 skills de agência (adotado 2026-10-03)

Regra de roteamento entre `growth-marketing-agency`, `copywriting-e-criativos`,
`trafego-pago`, `seo-e-conteudo`, `social-media`, `dados-e-bi-de-marketing`,
`propostas-comerciais`, `gestao-de-clientes-de-marketing`:

1. **Um dono por assunto.** Cada pedido tem uma skill dona (estratégia → growth; peça/copy →
   copywriting; mídia paga → trafego-pago; busca orgânica → seo; redes sociais → social-media;
   medição → dados-e-bi; vender meu serviço → propostas; operar cliente fechado → gestão).
2. **Não competir.** Se o pedido cruza dois domínios, a skill dona da DECISÃO toca o trabalho;
   lê só o arquivo necessário das irmãs, nunca duplica conteúdo entre respostas.
3. **Economia:** ler só as referências que a tarefa pede (não "por garantia"); rodar os
   `scripts/*.py` em vez de refazer conta no texto.
4. **Sequência de agência completa:** growth (estratégia) → copy (peças) →
   trafego/social/seo (execução) → dados (medição) → gestão (operação).
5. **Qualidade:** toda recomendação tem dono, prazo e critério de decisão. Número sem fonte é
   hipótese e precisa ser marcado como tal. Sem promessa de resultado garantido. PT-BR.
