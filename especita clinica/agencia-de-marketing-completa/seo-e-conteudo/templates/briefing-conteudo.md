| Risco | Mitigação | Dono | Prazo | Critério de liberação |
|---|---|---|---|---|
| Promessa não comprovada | reescrever com limite/fonte | | | |
| Conteúdo sensível | revisor qualificado | | | |

| CTA quebrado | QA ponta a ponta | | | |

- Não criar texto só para preencher palavra-chave.
- Não inventar avaliação, caso, número ou autoridade.
- Não publicar sem fonte ou marcar como hipótese o que ainda não foi verificado.

## 8. Checklist de publicação

- [ ] Intenção primária e URL canônica definidas.
- [ ] Resposta principal aparece cedo e é compreensível.
- [ ] Fontes, datas, autoria, revisão e limites conferidos.
- [ ] Texto é autoral; imagens têm licença/origem e alt útil.
- [ ] Links, CTA, telefone, formulário, schema e evento testados.
- [ ] Dono de atualização e gatilho de revisão registrados.
- [ ] Critério de decisão para 28–90 dias definido.
